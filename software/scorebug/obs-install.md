## OBS install steps
1. Download and install the latest version of OBS from https://obsproject.com/
    1. Select Cancel when the Auto Configuration wizard pops up
2. Download and run the setup for DistroAV https://github.com/DistroAV/DistroAV/releases/latest - select windows-x64-Installer.exe
    1. On the select additional tasks menu, leave everything checked
3. Download LiveVisionKit https://github.com/Crowsinc/LiveVisionKit/releases/latest
    1. Install Guide https://github.com/Crowsinc/LiveVisionKit/wiki/Install-Guide
4. Download and run the installer obs move transition https://obsproject.com/forum/resources/move.913/ - ignore any Windows Defender messages
